\question \emph{(Discrete logarithms and Pedersen commitments.)} 

  Recall the discrete logarithm assumption we discussed in class. See pseudocode on the left-hand side below. Let $\G$ be a group of order $p$ a prime and $G$ be a generator of $\G$. (Remember that $\G$ having prime order means every element has order $p$.) We will denote the identity of $\G$ as $0$.


  We can generalize the task of finding the discrete logarithm of a single group element to the task of finding a discrete logarithm \emph{relation} between 
  many elements. To define this, first let $\msm(\vec{x}, \vec{G}) = \sum_{i=1}^n \vec{x}_i \vec{G}_i$ denote the multi-scalar multiplication between a vector $\vec{x}$ of $n$ $\Z_p$ elements and an equal-length vector $\vec{G}$ of elements of $\G$. Then, a discrete logarithm relation between $n$ group elements $\vec{G} = (G_1, \ldots, G_n)$ is a nonzero vector $\vec{x} = (x_1, \ldots, x_n)$ of $\Z_p$ elements such that $\msm(\vec{x}, \vec{G}) = 0$. The pseudocode on the right below  defines a game $\mathsf{DLREL}^{\mathbb{G},p, n}$ that tasks an adversary $\advA$ with finding a discrete logarithm relation between $n$ random group elements. We denote the vector of all zeros as $\vec{0}$.

  \begin{figure}[h]
    \centering
    \hfpages{0.3}{
    \procedurev{$\mathsf{DL}^{\mathbb{G},G,p}(\advA)$}\\
    $x\getsr\mathbb{Z}_p$\\
    $x' \getsr \advA(xG, \mathbb{G}, G, p)$\\
    Return $x=x'$
    }{
      \procedurev{$\mathsf{DLREL}^{\mathbb{G},p, n}(\advA)$}\\
      $\vec{G}\getsr \mathbb{G}^n$\\
      $\vec{x} \getsr \advA(\vec{G}, \mathbb{G}, p)$\\
      Return $\msm(\vec{x}, \vec{G}) = 0 \wedge \vec{x} \ne \vec{0}$
      }

  \end{figure}
